## ✦ Vision

EFAC — **Education For All Children** — is centered on helping learners access education, guidance, mentorship and pathways toward a stronger future.

## 🎯 Focus Areas

- 📖 Academic support
- 👥 Mentorship
- 🧭 Career pathways
- 🏆 Leadership development
- 💙 Learner wellbeing
- 💻 Technology-enabled education

## 🛠️ Project

This repository contains the digital side of EFAC and can evolve as new tools, resources and community features are developed.
